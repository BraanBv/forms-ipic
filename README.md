# Registro al evento · TEC San Juan del Río
1. `npm install`
2. Copia tu credencial a `assets/credencial.png` (ajusta la posición del nombre con `NAME_Y=0.6 npm run dev`).
3. `ADMIN_USER=admin ADMIN_PASS=tuClaveSegura npm run dev`
4. Encuesta: http://localhost:3000 · Panel: http://localhost:3000/admin.html
Datos en `data/registros.json`. Para usar Assetio, edita solo `src/credential.ts`.
